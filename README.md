# L'AURUM Restaurant OS — Платформа ресторана высокой кухни + ERP/CRM (по аналогии с Dodo IS для Dine-In)

Комплексная веб-платформа, объединяющая **клиентский сайт для Гостей** (с минималистичным светлым дизайном `#faf9f6`, интерактивной схемой зала, предоплатой 50% от заказанных блюд, QR-меню за столом, живым трекером кухни и контролем качества каждого блюда) и **закрытую ERP-систему для персонала с жёстким разделением прав доступа (RBAC)** на базе **Supabase (PostgreSQL + Auth + Realtime + RLS)**.

---

## 📁 Структура проекта

* **[`index.html`](./index.html)** — Единая точка входа: портал Гостя + закрытая рабочая панель персонала (KDS Повара, Официант/Хостес, Бухгалтер, Дашборд Босса).
* **[`js/config.js`](./js/config.js)** — Файл конфигурации, где выделено место для вставки `SUPABASE_URL` и `SUPABASE_ANON_KEY`, а также настраиваются бизнес-правила ресторана (предоплата 50%, окно бесплатной отмены 24 часа, кэшбэк 5%).
* **[`js/db.js`](./js/db.js)** — Гибридный движок базы данных (`Supabase PostgreSQL` + `LocalStorage / BroadcastChannel` fallback для мгновенной работы без сборки).
* **[`js/app.js`](./js/app.js)** — Контроллер пользовательских сценариев Гостя и 4 ролевых терминалов персонала (RBAC).
* **[`css/styles.css`](./css/styles.css)** — Светлая минималистичная дизайн-система (*Warm Alabaster & Champagne Gold*).
* **[`supabase/schema.sql`](./supabase/schema.sql)** — Готовый SQL-скрипт для Supabase: 16 таблиц, внешние ключи, индексы, триггеры автоматического списания ингредиентов по техкартам и политики безопасности Row Level Security (RLS).

## ☁️ Как подключить вашу базу данных Supabase

1. Создайте проект на [supabase.com](https://supabase.com/).
2. Перейдите в **SQL Editor → New Query**, скопируйте и выполните весь код из файла [`supabase/schema.sql`](./supabase/schema.sql).
3. Перейдите в **Project Settings → API**, скопируйте `Project URL` и `anon public` ключ.
4. Вставьте их в файл [`js/config.js`](./js/config.js) (строки 18–19) **или** нажмите кнопку **«Supabase БД»** в верхней шапке сайта и вставьте ключи прямо в интерфейсе.
