# ВОСТОК ХАУС — Ресторан восточной кухни (Клиентская витрина + Отдельный сайт персонала + Supabase + ИИ)

Готовый к выкладке на **GitHub Pages** проект ресторана восточной кухни **«ВОСТОК ХАУС»** с сохранением всех данных в **Supabase** (PostgreSQL + Realtime + Auth + Storage + Edge Function ИИ).

## Структура проекта

- [`index.html`](./index.html) — **Клиентский сайт (Витрина ресторана)**:
  - Расширенное меню восточной кухни (26 блюд в 7 категориях: плов, шашлык, самса, манты и лагман, шурпа, закуски, десерты и напитки) с конструктором порций, выбором подачи с хлебом и добавками.
  - Все цены и расчёты в **казахстанских тенге (`₸`)**.
  - Два режима заказа без бронирования столов: **«Доставка»** и **«В зале (свободная посадка — гость сам находит удобное место)»**.
  - Регистрация и вход **только для клиентов** (без выбора ролей персонала).
  - Система оплаты **VOSTOK PAY** с двумя переключаемыми сценариями-заглушками: **«✅ Оплата прошла»** и **«❌ Оплата не прошла»** (с записью в таблицу `payment_logs` в Supabase).
  - Живой 5-шаговый трекер статуса заказа в реальном времени.
  - Плавающий виджет **ИИ-ассистента («Восток AI»)**, подключённый к данным вашей базы Supabase.
- [`staff.html`](./staff.html) — **Отдельный сайт для персонала («ВОСТОК ХАУС • ПЕРСОНАЛ»)**:
  - Регистрация сотрудников и выбор роли (`Повар / Кухня KDS`, `Кассир / Зал`, `Курьер`, `Управляющий / Админ`) + быстрый вход по ролям в 1 клик.
  - **Аналитика смены**: выручка в `₸`, средний чек, очередь кухни, лента всех заказов и журнал банковских транзакций (`payment_logs`).
  - **Экран кухни (KDS)**: карточки заказов с таймером SLA, попозиционной отметкой готовности каждого блюда и переводом статусов.
  - **Касса (POS)**: быстрый набор заказа в зале или на доставку с отправкой на экран кухни.
  - **Курьер**: очередь заказов на доставку.
  - **Меню, Стоп-лист и загрузка фото в Supabase Storage**: форма добавления нового блюда с загрузкой файла фотографии напрямую в публичный бакет `menu-images` в Supabase Storage (новое блюдо с фото сразу отображается на клиентском сайте `index.html`).
  - **Склад**: контроль остатков ингредиентов, приход (`+5`) и списание (`-1`).
  - **ИИ-ассистент персонала («Восток AI • ERP»)**: анализирует выручку, склад и очередь заказов по данным базы.
- [`supabase/schema.sql`](./supabase/schema.sql) — полный SQL-скрипт для создания всех таблиц, RLS-политик, Realtime и бакета `menu-images` в Supabase Storage.
- [`supabase/functions/vostok-ai/index.ts`](./supabase/functions/vostok-ai/index.ts) — код Supabase Edge Function для ИИ-ассистента (поддерживает ключи Gemini `AIzaSy...` и `AQ....`).

## Как развернуть в Supabase и на GitHub Pages

1. **База данных и Storage (Supabase SQL Editor)**:
   - Откройте ваш проект в [Supabase Dashboard](https://supabase.com/dashboard) → **SQL Editor** → **New query**.
   - Скопируйте и выполните весь код из файла [`supabase/schema.sql`](./supabase/schema.sql). Он создаст все таблицы, включит Realtime и создаст публичный бакет `menu-images` для загрузки фотографий блюд.
2. **ИИ-ассистент (Supabase Edge Functions)**:
   - Если у вас в проекте уже развёрнута функция `ertis-ai` с секретом `GEMINI_API_KEY`, сайт подключится к ней автоматически.
   - Либо создайте новую функцию `vostok-ai`, вставьте код из [`supabase/functions/vostok-ai/index.ts`](./supabase/functions/vostok-ai/index.ts) и отключите `Verify JWT`.
3. **Публикация на GitHub Pages**:
   - Загрузите файлы `index.html`, `staff.html`, `shared-data.js`, `images.js`, `README.md` и папку `supabase/` в ваш репозиторий на GitHub.
   - Включите **Settings → Pages → Deploy from a branch (`main`)**.
   - Клиентская витрина будет доступна по адресу `https://<ваш-логин>.github.io/<репозиторий>/`, а сайт персонала — по адресу `https://<ваш-логин>.github.io/<репозиторий>/staff.html`.
